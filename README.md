# Qelvexa

Next.js 16.3.6 + TypeScript + Tailwind CSS 4. Frontend-only, no backend: all PDF/image processing runs in the browser. PWA-installable, Persian (default) + English, dark (default) + light theme.

## Run locally
```
npm install
npm run dev
```
Open http://localhost:3000

## Build
```
npm run build
npm start
```
